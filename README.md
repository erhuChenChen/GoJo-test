# GoJo 🥖 - 个人成长记录与图文管理工具

GoJo 是一款完全本地化、无联网依赖的个人图文记录与成长管理 App。旨在帮助用户记录某一个或多个领域的学习时长、管理分类、追踪目标进度以及统计收支情况。

## ✨ 核心功能

- **纯本地存储**：所有数据（图片、文字、分类、标签）仅保存在设备本地，不依赖任何云端服务器，极致保护隐私。
- **多领域管理**：支持自定义领域（如绘画、健身、读书等），不同领域的数据、分类、标签完全独立。
- **精细化图文记录**：支持多图上传、文字说明、评论记录，支持自定义分类与标签。
- **进度与目标追踪**：自定义打卡目标或自动统计目标，支持卡片进度条与圆环展示。
- **仪表盘统计**：自定义勾选需要展示的统计卡片（时长、收入、支出、记录数等）。
- **极简 UI 与主题换肤**：内置深色极简、浅色清新等多种主题，支持跟随系统日夜切换。
- **安全备份机制**：支持将所有数据（含图片）打包导出为专用备份文件，换设备一键导入恢复。

## 🛠️ 技术栈

- **前端**：HTML5 / CSS3 / Vanilla JavaScript
- **本地数据库**：IndexedDB / LocalStorage
- **打包框架**：HBuilderX 5+ App (WebView 混合开发)

## 🚀 如何使用

1. 前往仓库右侧的 **Releases** 页面。
2. 下载最新版本的 `.apk` 安装包。
3. 安装到 Android 手机（需允许安装未知来源应用）。
4. 打开 App，选择你的领域，即可开始记录。

## 🔒 数据安全提示

由于数据纯本地化，**卸载 App 或清理手机存储会导致数据丢失**。请务必定期使用 App 内的“导出数据”功能，将 `.gtbackup` 备份文件保存至网盘或电脑中。
